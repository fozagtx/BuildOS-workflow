# YouTube Content Studio

Use this as the one master skill for YouTube video work. Do not rely on separate script-writing skills for normal YouTube creation tasks; this skill contains the core workflows that were previously split across the general YouTube script writer, investigative retention strategy, script-forensics cleanup, Thumbnail Architect, and AI33 Pro media client.

## Mandatory Preflight

Before writing any script, prompt, character setup, thumbnail idea, voiceover, title, caption, metadata, or media plan:

1. Run an originality pass. Avoid copying or closely mirroring hooks, plots, captions, character naming patterns, thumbnail framing, or story beats from existing YouTube videos.
2. Run the blocked-name pass. Check every character, family, business, location, food reference, title, caption, and prompt against the blocked list below.
3. Avoid recommending or naming the writing AI/tool the user explicitly said to avoid in the screenshot.
4. If the user's brief contains a blocked name, replace it with a fresh alternative unless the user explicitly says they are intentionally keeping it for that exact project.
5. Run a script-forensics pass before the script moves to thumbnail, voiceover, captions, image prompts, or media generation.
6. Keep the output production-ready. The user usually wants words, beats, prompts, and assets they can use directly.

## Studio Workflow

For any YouTube video request, apply these modules in order:

1. Intake and classify the video.
2. Build the retention strategy.
3. Write or structure the script.
4. Run the retention, originality, blocked-name, and script-forensics self-check.
5. Generate production support only after the forensic pass: title, high-CTR thumbnail concepts, image prompts, voiceover, sound effects, captions, or AI33 Pro task commands.

### Intake

Infer missing details when the user gives enough context. Ask only when the missing answer would change the output materially.

Gather or infer:

- Topic or angle: the one idea the viewer should leave with.
- Target length: under 3 minutes, 3-8 minutes, 10+ minutes, or documentary length.
- Audience: beginner, expert, mixed, or niche community.
- Format: educational, commentary, documentary, story, faceless narration, VSL/sales, short, or cinematic fiction.
- Tone: casual, docu-style, tense, emotional, funny, direct response, or cinematic.
- Research/source material: facts, URLs, transcript notes, stats, quotes, examples, or user-provided lore.
- Output needed: hook only, outline, full script, rewrite, retention audit, thumbnail, prompt pack, voiceover, or full production kit.

If the topic needs current facts, stats, public claims, news, laws, prices, or exact source attribution, verify with current sources before writing. Do not invent stats, quotes, dates, or named facts.

## Retention Strategy

Every script needs a retention engine. Choose the engine based on format.

### General YouTube Engine

Use for standard educational, commentary, explainer, entertainment, and faceless content.

Structure:

1. Hook, first 5 seconds:
   - One sentence that promises a payoff or opens a loop.
   - No throat-clearing.
   - Use curiosity gap, bold claim, visual pattern interrupt, or immediate contradiction.
2. Setup, seconds 5-20:
   - Why this matters now.
   - Who this is for.
   - The sharper promise of the video.
3. Body:
   - 2-4 sections for a 5-8 minute video.
   - One idea per section.
   - Concrete examples beat abstract explanations.
   - Every 30-45 seconds, add a re-hook, pattern break, twist, visual change, or memorable line.
4. Payoff:
   - Close the exact loop opened in the hook.
   - Give the one takeaway the viewer can repeat.
5. CTA:
   - One ask only.
   - Tie the ask to the video.
   - End on a clean visual or spoken beat.

### Investigative And Documentary Engine

Use for documentary, investigative, mystery, crime, geopolitics, business drama, history, systemic failure, or long-form story videos.

Lock these four answers before writing prose. Infer from the brief when possible, otherwise ask:

1. Macro question: the one question the whole video answers.
2. Human anchor: the named person or composite the viewer follows, with role and one personal detail.
3. Dramatic irony layer: what the viewer knows that people in the story do not.
4. The 85 percent reveal: the reveal near the end that recontextualizes the early anomaly.

Retention rule:

- Plant one macro question in the first 90 seconds.
- Do not answer it before the 85 percent mark.
- Use every other technique to keep the viewer engaged while they wait.

Pick a structural signature by topic, without copying any existing channel's exact voice:

- Geopolitics, crime, intelligence: dramatic irony and countdown pressure.
- Conspiracy, unsolved, anomaly stories: pattern of anomalies, false summit, coherent reveal.
- Niche historical or corporate stories: small unknown event becomes a larger system.
- Policy, infrastructure, systemic failure: show how the conditions still exist today.
- Manhunt, chase, dual-track investigations: cold open rewind and parallel pursuit.

Beat sheet template:

```text
[0:00-1:30] HOOK
- Opener:
- Macro question:
- Human anchor:
- Anomaly planted:

[1:30-10%] ACT 1 - ESTABLISH
- Stakes:
- First open loop:
- Detail that will matter later:

[10%-60%] ACT 2 - INVESTIGATE
- Re-hook pattern:
- Beats:
  1.
  2.
  3.

[60%-75%] PIVOT
- How the specific story becomes larger:

[75%-85%] FALSE SUMMIT
- Apparent answer:
- Why it is incomplete:

[85%-100%] PAYOFF
- Reveal:
- Answer to macro question:
- Final aftertaste:
```

For documentary requests, show the beat sheet before writing full prose unless the user clearly asks for a draft immediately.

## Writing Rules

- Write spoken words as the main output.
- Put visual notes in `[VISUAL: ...]` tags.
- Use short sentences that sound natural aloud.
- Use contractions.
- One idea per sentence when pacing matters.
- Do not use vague placeholders like "a victim", "a woman", "officials", or "some people" when a named human, role, or concrete detail would hold attention better.
- Do not lecture. Create discovery.
- Do not bolt twists onto the end. Plant anomalies early so the reveal feels earned.
- Do not manufacture tension with vague lines. Use dramatic irony, stakes, specificity, and open loops.
- Do not include multiple CTAs.
- Do not invent proof, dates, quotes, results, or sources.
- Avoid useless repetition. Do not repeat a phrase, sentence shape, explanation, emotional beat, or hook unless it is a deliberate callback that earns its place.
- Avoid AI-slop contrast patterns such as `not just X, but Y`, `not only X, but Y`, `it is not X, it is Y`, `more than just X`, and `it is not about X, it is about Y`. State the stronger idea directly.

## Retention Self-Check

Before delivering, fix the script if any answer is weak:

- What exact loop opens in the first 5-10 seconds?
- Why would the viewer keep watching at 30 seconds?
- Where is the first pattern break?
- What gets teased but not resolved too early?
- Does every section close one loop and open another?
- Is the payoff the answer promised by the hook?
- Did the script avoid the blocked names and disallowed tool mention?
- Does anything resemble a known YouTube hook too closely?
- Did the script-forensics pass remove useless repetition and AI-slop contrast?

### Anti-Plastic Human Image Standard

For every generated image prompt that includes a human face, visible skin, a portrait, a close-up, a dramatic reaction shot, or a character-focused scene, add a realistic skin texture block. The purpose is to stop the plasticky AI look and force tactile, imperfect, photographic human detail.

Add this to the main prompt, adapted to the specific character and shot:

```text
SUBJECT: A hyper-detailed, photorealistic portrait or cinematic character shot of <describe the subject, emotion, age, ethnicity, wardrobe, and role in the scene>.

LIGHTING & COMPOSITION: <describe the scene lighting, lens, depth of field, camera angle, and focal point>. Use natural cinematic lighting, shallow depth of field when appropriate, with focus on the eyes, mouth, and emotional expression.

TEXTURE & QUALITY: Extreme photorealism, 8k resolution, CGI-level detail, uncanny-valley realism only in the sense of maximum physical detail, not fake plastic smoothness.

INTRICATE FACIAL DETAILS:
SKIN: Visible vellus hair, peach fuzz catching the light along the jawline, cheek, temple, and forehead. Subtle natural melanin variance and mottling across the cheeks. Slight redness around the nose where appropriate. Real pores, visible skin grain, stochastic micro-texture, subtle oil sheen on nose and forehead, and fine topographical variation. Faint blue-green subdermal vascularity visible beneath thin skin at the temples, under-eyes, and inner eye corners where anatomically appropriate.
EYES: Complex iris striations and texture, natural crystalline catchlights, wet reflective lower waterline, faint capillaries in the sclera, and tiny red vessels at the eye corners.
LIPS: Natural dry texture, small vertical lines, uneven light catch, slight chapping or cracked detail when it fits the scene emotion.

STYLE/AESTHETICS: Cinematic, gritty, highly textured, naturalistic high-end color grading, emotionally realistic, premium drama still.
```

Add this to the negative prompt for human images:

```text
ANTI-PLASTIC NEGATIVE PROMPT:
No smooth wax skin, no airbrushed face, no poreless plastic skin, no beauty-filter skin, no glossy mannequin face, no doll-like texture, no cloned or twin-like faces, no distorted hands, no extra limbs, no unreadable fake text, no cartoon style, no generic stock-photo look.

SKIN TEXTURE REQUIREMENTS: Skin must be highly textured with perceptible pores, visible skin grain, subtle stochastic noise, micro-surface detail, natural oil sheen, vellus hair, melanin variance, minor redness, capillary visibility, faint blue-green subdermal veins, micro-freckles when appropriate, and subtle mottling.

LIPS AND EYES REQUIREMENTS: Lips must show natural vertical lines and dry texture rather than smooth plastic. Eyes must show iris striations, wet lower waterline, realistic sclera capillaries, and natural catchlights.

QUALITY REINFORCEMENT: 8k, highly detailed, macro photography texture, zero airbrushing, photorealistic skin, high-frequency detail, filmic grain.
```

Do not paste the block blindly into non-human object-only prompts. For scenes with people in the distance, use a shorter version focused on non-plastic skin, distinct faces, and realistic eyes. For close-ups and thumbnails, use the full block.

Always run the blocked-name pass on prompt text too.

The client reads API keys from environment variables or local env files:

- `AI33_API_KEY`
- `XI_API_KEY`
- `AI33_XI_API_KEY`

When generating media, prefer:

```bash
python3 scripts/ai33_client.py image-generate --text-file PROMPT.txt --wait --download --out-dir OUT_DIR
```

Preferred image model for this workflow:

- `gemini-3-pro-image-preview`

Fallback image model:

- `gpt-image-2`

For voiceover:

```bash
python3 scripts/ai33_client.py voices --provider edge --language Vietnamese --gender Female
python3 scripts/ai33_client.py tts --text-file SCRIPT.txt --voice-id edge_vi-VN-HoaiMyNeural --with-transcript --wait --download --out-dir OUT_DIR
```

Use AI33 v3 voice IDs exactly as returned from the v3 voice library. Valid prefixes are `elevenlabs_`, `minimax_`, `clone_`, `edge_`, `kokoro_`, `vbee_`, and `fishaudio_`. The v3 TTS and dialogue endpoints use multipart FormData.

For multi-speaker dialogue:

```bash
python3 scripts/ai33_client.py dialogue \
  --text-file DIALOGUE.txt \
  --speakers '[{"voice_id":"elevenlabs_hpp4J3VqNfWAUOO0d1Us","speed":1},{"voice_id":"minimax_male-qn-qingse","speed":1}]' \
  --delay 0.4 \
  --with-transcript \
  --wait \
  --download \
  --out-dir OUT_DIR
```

Use `pronunciation_dictionary_id` only through `--pronunciation-dictionary-id`; it affects audio generation, not the original text or transcript labels.

For sound effects:

```bash
python3 scripts/ai33_client.py sound-effect --text-file SFX_PROMPT.txt --wait --download --out-dir OUT_DIR
```
