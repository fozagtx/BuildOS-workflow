# /reject-framing

Score a framing and reject the obvious, feel-safe versions.

## Inputs

- Current framing
- Workaround map, if available
- Why the user likes this framing

## Steps

1. Split bundled symptoms.
2. Score the four signals.
3. Name default-reject ideas (delivery, education, marketplace, dashboard, AI for X).
4. Explain why each feels safe and who it actually serves.
5. Say go or no-go to sharpening. All 1-2s is no-go. Mixed 2-3s means split and rescore.
6. If the user is attached to a rejected framing, still reject it.

## Output

- Signal scores
- Rejected framings
- Split symptoms
- Go / no-go
