# /problem-sprint

Run the full discovery workflow from messy framing to ranked problems.

## Inputs

- Original framing or idea
- Implied solution, if any
- Decision it informs
- Expected format

## Steps

1. Intake
2. Restate from the worker
3. Map workarounds
4. Score signals
5. Reject obvious framings
6. Sharpen 2-3 problems
7. Produce the report using the six headings in `skill/sharpen.md`. No solution section.
8. If the workaround map is empty, emit the suspect report from `skill/edge-cases.md`. Leave ranked problems empty.
9. If the user named a buyer or market, run the three doer questions first.

## Output

- Discovery report
- Signal scores
- Rejected framings
- Ranked sharpened problems
