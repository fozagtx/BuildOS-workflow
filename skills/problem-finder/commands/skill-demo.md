# /skill-demo

Package the discovery workflow as a live demo.

The expected report is [evals/canonical-market-woman.md](../evals/canonical-market-woman.md). Use that file verbatim. Do not invent a second example.

## Inputs

- Demo prompt (default: market woman)
- Target audience
- Expected demo length

## Steps

1. Show the messy original framing from the canonical report.
2. Show the worker restatement.
3. Show current workarounds.
4. Show signal scores.
5. Show rejected obvious framings.
6. Show ranked sharpened problems.
7. Show why jumping to a product would have been the wrong move.
8. If they then ask "what should we build?", stay inside sharpened #1 only.

## Output

- Demo script
- Demo prompt
- Expected report (the canonical file)
- Before/after contrast
