# /map-workaround

Map what the worker does today. Flag the problem if nothing is being done.

## Inputs

- Named worker, or a framing to extract one from
- Job they are trying to finish
- Context about tools, hours, or informal networks

## Steps

1. Name the doer. If the prompt names owners, SMEs, or "the market", ask the three doer questions.
2. List workarounds by category. Do not invent any.
3. Attach a cost to each.
4. Note who benefits from the mess.
5. Flag empty maps as suspect.

## Output

- Worker
- Workaround list
- Costs
- Suspect flag, if any
