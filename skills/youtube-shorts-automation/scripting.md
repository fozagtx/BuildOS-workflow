# Scripting Workflow

Use this file when the user wants a script structure, script batch, hook rewrites, or a 20-40 second Shorts script.

## Core Script Structure

Default structure:

1. Hook: 0-3 seconds
2. Open loop: make the viewer need the answer
3. Body: simple steps or story beats
4. Delay: hold the key moment slightly longer
5. Payoff: reveal the reason, result, or twist
6. Engagement CTA: ask a real question

## Hook Formulas

Use hooks that create immediate curiosity:

```text
Look... why is [specific strange thing] happening?
Nobody noticed [specific detail] until this happened.
This looks normal, but watch what happens next.
The reason [person/object] did this is not what you think.
In [number] seconds, this completely changes.
```

Course example pattern:

```text
Weak: They are dropping marbles.
Strong: Look... why are they dropping marbles in a bathroom?
```

## Retention Tricks

Use these naturally:

- Ask questions.
- Keep sentences short.
- Avoid long setup.
- Stack curiosity.
- Delay the key moment.
- Use transitions like "But then..." or "This is where it changes."
- End with a payoff, not a vague cliffhanger.

## Script Rules

For a standard Short:

- Keep it 20-40 seconds unless the user requests otherwise.
- Start with a strong hook.
- Use short, simple sentences.
- Keep pacing fast.
- Build curiosity throughout.
- End with a strong payoff.
- Add a genuine CTA.
- Do not copy-paste competitor scripts.
- Manually rewrite the hook before production.

## Style Training Prompt

Use this before generating scripts from examples:

```text
Act as a YouTube Shorts script analyst.

Study the examples carefully and identify the exact script style and structure.

Focus on:
- How the video starts
- How the ideas flow from beginning to end
- Sentence style: short, punchy, simple
- How curiosity is built
- Transitions between parts
- How the ending is delivered

Then create a simple, reusable script structure I can follow for any topic.
Do not write a script yet. Only give me the structure.
```

## Quality Checklist

Before finalizing a script:

- First line creates curiosity in under 3 seconds.
- No sentence is bloated.
- The script can be read aloud naturally.
- The payoff answers the open loop.
- It does not make false claims.
- It does not require copyrighted visuals unless the user has a rights-safe plan.
