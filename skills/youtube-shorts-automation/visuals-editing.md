## Anti-Copy Clip Method

Use this when inspired by a viral video:

1. Do not directly copy the viral video.
2. Screenshot a representative frame only for research.
3. Use visual search to identify similar clean sources.
4. Find clips with no captions, no watermarks, and a clear rights path.
5. Prefer stock footage, licensed footage, self-made footage, or platform-provided assets.
6. Build a new edit with original narration, pacing, captions, and emphasis.

If the user asks to download Instagram, TikTok, or YouTube clips, frame it carefully:

- Only download public content when allowed by the platform and rights holder.
- Do not download private content.
- Do not reupload someone else's video as the main content.
- Use download tools only for assets the user owns, has permission to use, or is using within a rights-safe transformation plan.

The supplied knowledge base mentions SaveFrom.net, Publer.io, and desktop tools such as 4K Video Downloader. Treat these as convenience tools, not copyright permission.

## Clip Target

For one Short, gather:

- 4-6 clean clips for a simple edit
- 8-12 clips for a faster-paced edit
- 1 strong first-frame visual
- 1 payoff visual
- Optional symbols, arrows, circles, or zooms for emphasis

## CapCut or VEED Setup

Use:

- Aspect ratio: 9:16
- Resolution: 1080 x 1920
- Avoid black bars
- Avoid unnecessary 4K exports if they slow upload or playback
- Remove original clip audio unless it is licensed and intentionally used

## Retention Editing Steps

### 1. Audio First

1. Import the voiceover.
2. Remove all long pauses.
3. Cut silent gaps tightly.
4. Keep the script moving.

### 2. Hook Optimization

First 3 seconds should use:

- Most engaging clip
- Freeze frame for 0.5-1 second if it creates curiosity
- Zoom effect
- Arrow or circle indicator
- Short sound effect, such as a light ding
- Large readable on-screen phrase

### 3. Clip Placement

Match visuals to the voiceover, but do not reveal everything too early. Delay the key moment when it improves curiosity.

### 4. Effects

Use effects to guide attention:

- Keyframe zooms
- Smooth transitions
- Subtle filters
- Speed ramps only when useful
- Sound effects for key moments

Avoid effect overload. The viewer should follow the story, not admire the timeline.

### 5. Captions

Captions should be:

- Readable on mobile
- Grammatically clean
- High contrast
- Timed to the voice
- Not covering the main subject
