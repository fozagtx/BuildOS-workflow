# Thumbnails and Titles

Use this file when the user needs high-CTR faceless thumbnail templates, title formulas, or batch packaging.

## Thumbnail Principles

The supplied knowledge base recommends:

- Bright contrasting colors
- Huge bold text
- 3-6 words maximum
- Sans-serif fonts such as Impact or Arial Black
- Arrows, circles, and simple symbols to point at the key element
- Curiosity hooks
- Numbers, questions, or before-after framing
- Stock visuals or symbolic objects for faceless channels

Recommended sizes:

- YouTube thumbnail: 1280 x 720
- Shorts or Reels vertical cover: 1080 x 1920

## Free Thumbnail Tools

1. Canva: https://canva.com/create/youtube-thumbnails
2. PosterMyWall: https://postermywall.com
3. Adobe Express: https://adobe.com/express/create/thumbnail/youtube
4. Canva Magic Studio for AI-assisted concepts

Tool limits and free features can change. Verify before building a batch workflow around one tool.

## Batch Thumbnail Workflow

1. Open Canva or a similar editor.
2. Search for free YouTube thumbnail templates.
3. Pick one bold visual system.
4. Duplicate it 20-50 times.
5. Swap:
   - Main text
   - Background or object
   - Arrow/circle placement
   - Accent color
6. Keep the same broad style for brand recognition.

## Title Principles

For Shorts, the first 40 characters matter most.

Good titles:

- Create curiosity
- Stay truthful
- Match the video payoff
- Avoid vague clickbait
- Use simple language

Examples:

```text
The One Detail Everyone Missed
Why This Clip Feels So Wrong
This Changed Everything in 10 Seconds
He Thought It Was Over
The Reason Is Stranger Than It Looks
```

## Title Formulas

```text
Why [specific event] actually happened
The [number] second detail that changed [topic]
Nobody noticed [specific detail]
This looks normal until [turning point]
The real reason [person/object] did [action]
```

## Packaging Quality Gate

Before finalizing:

- Thumbnail text is 3-6 words.
- Title and thumbnail point to the same payoff.
- The packaging does not promise something the video never delivers.
- Text is readable on a small phone screen.
- The image is not blurry or random.
