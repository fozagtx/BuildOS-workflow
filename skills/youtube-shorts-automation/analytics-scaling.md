# Analytics and Scaling

Use this file when the user asks why videos are getting low views, how to improve retention, or how to scale a Shorts system.

## Core Principle

You are not just creating content. You are engineering attention:

- Hook fast.
- Build curiosity.
- Delay payoff.
- Deliver the answer.
- Make the viewer want to replay or comment.

## Key Metrics

Track:

- Viewed vs swiped away
- Average view duration
- Retention percentage
- Replay behavior
- Likes per view
- Comments per view
- Subscribers gained per video
- Returning viewers
- Traffic source

## Retention Targets

The course notes give these ambitious targets:

| Video Length | Target Retention |
|--------------|------------------|
| 15-40 seconds | 120-150 percent |
| 50-60 seconds | 85 percent or higher |

Interpretation:

- Over 100 percent retention means viewers are replaying.
- Short videos need stronger replay loops.
- Longer Shorts need fewer slow spots and clearer payoff.

## Low-View Diagnosis

### Case 1: 0 Views

Possible causes:

- New account trust issue
- Channel not warmed up
- Upload still processing
- Visibility setting issue
- Policy or copyright issue
- Content not entering Shorts feed

Fix:

1. Check upload visibility.
2. Check Studio restrictions.
3. Warm up the account naturally.
4. Post one clean, original Short per day.
5. Avoid rapid batch uploads on a brand-new channel.

### Case 2: Stuck at a Small Plateau

Possible causes:

- Weak first 3 seconds
- Low viewed-vs-swiped rate
- Slow voiceover
- Visual mismatch
- Payoff too late or too weak
- Repetitive template

Fix:

1. Rewrite the hook.
2. Use the strongest visual first.
3. Cut pauses.
4. Add clearer captions.
5. Move payoff earlier.
6. Create 3 variants of the same topic.

### Case 3: Stuck Around a Larger Plateau

The course notes point to average retention as the main bottleneck.

Fix:

1. Compare top 3 and bottom 3 videos.
2. Identify where viewers drop.
3. Shorten intros.
4. Delay key reveal without padding.
5. Create a sequel to the best performer.
6. Test title and thumbnail style on the next upload.

## Scaling Strategy

Start:

- 1 video per day
- 1 niche
- 1 format

Then:

- 2-3 videos per day if quality stays high
- Reuse winning idea structures
- Build multiple series, not random topics
- Expand to adjacent channels only after one workflow is stable

Do not scale a broken format. Volume amplifies the current system, including its weaknesses.

## Experiment Backlog

Test one change at a time:

- Hook wording
- First visual
- Voice speed
- Video length
- Caption style
- Payoff timing
- CTA question
- Topic angle
- Upload time
- Thumbnail frame
