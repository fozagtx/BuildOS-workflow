# YouTube Shorts Automation Skill

This skill helps a user learn and operate a systematic YouTube Shorts workflow from zero: channel setup, warm-up, niche selection, research, scripting, voiceover, visuals, editing, upload cadence, analytics, and monetization readiness.

Use it as a teaching and operating system. The output should help a beginner know exactly what to do next, while helping an experienced creator batch work faster without risking repetitive or reused-content problems.

## What This Skill Is For

Use this skill when the user asks for:

### Channel Foundation
- Creating a new Shorts channel
- Warming up a fresh channel
- Setting channel name, handle, profile image, and basic info
- Avoiding immediate spam-like posting

### Niche and Research
- Choosing between commentary, streamer clips, movie recap, storytelling, or similar faceless Shorts niches
- Studying benchmark channels
- Finding viral videos and saving ideas
- Turning competitor videos into reusable script structures without copying

### Production Workflow
- Generating 20-40 second scripts
- Creating batches of Shorts scripts, titles, and thumbnail briefs
- Producing TTS narration and cleaning audio
- Finding royalty-free or clean licensed clips
- Editing retention-focused Shorts in CapCut, VEED, or similar tools

### Packaging and Upload
- Writing curiosity titles
- Designing faceless thumbnails
- Posting consistently without flooding
- Building a 30-45 day sprint or monthly calendar
- Cross-posting to TikTok or Reels when appropriate

### Analytics and Monetization Safety
- Diagnosing 0 views, low views, or videos stuck around a plateau
- Improving retention and replay rate
- Auditing originality, AI disclosure, Content ID, and reused-content risks
- Preparing for YouTube Partner Program review

## Out of Scope

Do not use this skill to:

- Promise specific monthly income, monetization approval, or viral results
- Encourage fake views, bought subscribers, automated comments, or engagement manipulation
- Reupload copyrighted clips without permission or meaningful transformation
- Download private content or bypass platform access controls
- Give legal advice about fair use, copyright, tax, or business compliance

When a question depends on current YouTube policy, verify the official YouTube source before giving definitive threshold or disclosure guidance.

### 2. Start With the Earliest Unresolved Layer

Use this order unless the user already has strong artifacts:

1. Channel status and warm-up
2. Niche and benchmark channels
3. Research and idea bank
4. Script structure and script batch
5. Voiceover and audio polish
6. Visual sourcing and edit plan
7. Title, thumbnail, and upload settings
8. Analytics review
9. Monetization readiness
10. Scaling plan

Do not build a monetization plan if the workflow is still copying clips. Do not write 100 scripts if the niche is unclear. Do not diagnose low views without checking retention, hook, account age, upload consistency, and originality.

### 3. Gather Minimal Context

Ask for only the details that change the output:

- Target niche
- Channel age and upload count
- Device/editor available
- Daily time available
- Whether the user can record voice or wants TTS
- Whether they have rights to the clips they plan to use
- Current analytics if troubleshooting
- Deadline or goal, if building a sprint

If the user wants a beginner path and gives no context, default to a fresh channel, 1-2 hours per day, free tools, and 1 Short per day until the workflow is stable.

### 4. Protect Originality

Every production plan should add value through at least three of:

- New hook
- New script structure
- Original commentary or narration
- New pacing and edit
- Clean licensed or royalty-free visuals
- Captions and on-screen emphasis
- New title and thumbnail
- Clear educational, storytelling, or entertainment payoff

### 5. Produce Concrete Outputs

Prefer outputs like:

- Day 0-7 channel warm-up checklist
- Niche scorecard
- Viral idea bank table
- Reusable script structure
- Script batch with titles and CTAs
- Voiceover direction
- Clip sourcing checklist
- CapCut edit map
- Thumbnail and title brief
- 30-day content calendar
- Monetization readiness audit
- Analytics experiment plan
