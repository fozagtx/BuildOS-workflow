## Niche Selection Criteria

Score each niche from 1-5:

1. Viral demand: Are recent Shorts getting strong views?
2. Production ease: Can the user make 1-3 videos daily?
3. Originality potential: Can the user add new commentary, framing, narration, or editing?
4. Clip risk: Are assets licensed, royalty-free, self-made, or clearly transformable?
5. Retention fit: Can the niche support curiosity, delay, and replay?
6. Monetization safety: Would the channel survive reused-content review?

Recommend the niche with the best mix of demand, production speed, and originality.

## Manual Research Method

Use this method when the user wants high control.

1. Open YouTube in a clean browsing session.
2. Go to the Shorts feed.
3. Search or watch inside the target niche.
4. Look for videos with:
   - 1M+ views
   - High likes and comments
   - Or high views with weak execution that can be improved
5. Prefer videos posted within the last 5 months.
6. Save links in a document or spreadsheet.
7. Capture:
   - Hook
   - Topic
   - Video length
   - Views
   - Like/comment signal
   - Structure
   - Visual pattern
   - Why it worked
   - How to make an original version

## AI-Assisted Research Method

Use this when the user wants faster scaling.

1. Find viral videos, especially videos without voiceover.
2. Ask an AI tool to describe what happens in the video.
3. Ask an AI tool to identify the script structure from competitor examples.
4. Generate a new script from the structure, not a copied script.
5. Manually rewrite the hook and payoff.

Useful analysis prompt:

```text
Act as a YouTube Shorts script analyst.

Study the examples and identify the script style and structure.

Focus on:
- How the video starts
- How the ideas flow
- Sentence style
- How curiosity is built
- Transitions
- Ending and payoff

Create a reusable structure I can use for a new topic.
Do not write a script yet.
```
