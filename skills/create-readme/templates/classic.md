## Rules for this template

- Do **not** include LICENSE, CONTRIBUTING, or CHANGELOG sections (dedicated files cover those).
- Prefer a tight header (title, badges optional, short intro), then features, prerequisites, install, usage, and optional config/troubleshooting.
- Keep sections short. Link out for deep docs.
