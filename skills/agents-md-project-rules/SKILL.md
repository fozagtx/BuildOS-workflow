# AGENTS.md Project Rules

Create project-level `AGENTS.md` files from bundled fragments copied from
`remorses/AGENTS.md` at commit `6b37c052626232f45885ad4bf94e128763069009`.

## Workflow

1. Inspect the target project before writing:
   - `package.json`, lockfiles, `tsconfig.json`, `components.json`, framework configs
   - `prisma/schema.prisma`, `.changeset/`, `vercel.json`, `fly.toml`, `doppler.yaml`
   - dependency names in `dependencies`, `devDependencies`, and workspace manifests
2. Select the smallest useful fragment set. Start with `core.md`, `docs-writing.md`, and
   `github.md`; add stack-specific fragments only when the project actually uses that tool.
3. Generate `AGENTS.md` with the bundled script instead of retyping fragments.
4. If an `AGENTS.md` already exists and is not generated by this plugin, generate to
   `AGENTS.generated.md`, review both files, then merge deliberately.

## Generator

Run from the target project root:

```bash
python3 <skill-dir>/scripts/build_agents_md.py --detect . --output AGENTS.md
```

Useful alternatives:

```bash
python3 <skill-dir>/scripts/build_agents_md.py --profile react-router --output AGENTS.md
python3 <skill-dir>/scripts/build_agents_md.py core.md typescript.md pnpm.md vitest.md --output AGENTS.md
python3 <skill-dir>/scripts/build_agents_md.py --list
```

The script refuses to overwrite a hand-written `AGENTS.md` unless `--force` is passed. Use
`--force` only after reading the existing file.

## Fragment Selection

Prefer detection. If choosing manually, use this map:

- TypeScript: `typescript.md`
- pnpm workspace: `pnpm.md`
- React: `react.md`
- React Router v7: `react-router.md`
- Tailwind or shadcn/ui: `tailwind.md`, `shadcn.md`
- Browser testing: `playwright.md`
- Unit testing with Vitest: `vitest.md`
- Prisma: `prisma.md`
- Zod: `zod.md`
- Sentry: `sentry.md`
- Stripe: `stripe.md`
- Vercel AI SDK: `vercel-ai-sdk.md`
- Vercel deploy/log work: `vercel.md`
- Fly.io: `fly.md`
- Doppler: `doppler.md`
- Three.js: `threejs.md`
- Spiceflow: `spiceflow.md`
- CLI work with goke/cac: `goke.md`, `cac.md`
- Long-running terminal tasks: `tmux.md`

Avoid `old-gitchamber.md` unless the user explicitly asks for legacy gitchamber behavior.
Read `references/upstream.md` when you need the exact bundled file inventory.
