# Best fonts & how to use them

Concrete face picks and usage rules from the Typography & Layout Masterclass. Classifications alone are not enough — **how** you set a face matters as much as which face you pick.

## Decision order

1. Name the mood + content load (UI vs editorial vs campaign)
2. Pick classification → pick a **specific face** from the lists below
3. Assign roles (display / body / meta)
4. Set **weight, size, tracking, leading, case** using the usage rules
5. Only then pair a second face

---

## Instructor favorites (use these mental models)

Even if you cannot license the exact face, match its **role + behavior**.

### Serif favorites

| Face | Character | Best use | Avoid / notes |
|------|-----------|----------|---------------|
| **OC Bartok** (or historic old-style) | Traditional, polished, “high finish” | Headlines **and** paragraphs; heritage brands | None strong — safe workhorse for classic tone |
| **Sol Display** (Didone-leaning display serif) | Handcrafted swing, high contrast | Large words, headlines; **italic** for short editorial blocks | Regular at paragraph sizes — hard to read; not for long UI copy |
| **Adobe Caslon Pro** (old-style all-rounder) | Even stroke, smooth, flexible | Long copy + headlines; regular / bold / italic | Default pick when you have lots of paragraphs |

**Serif subcategory cheats:**

- Old style (Garamond, Caslon) → reading + tradition
- Transitional (Times, Georgia) → balanced, familiar
- Didone (Bodoni, Didot) → fashion/luxury **display**; thin strokes fail at small size / low res
- Slab → bold, squared, modern/strong presence

### Sans favorites

| Face | Character | Best use | Tracking / setting |
|------|-----------|----------|--------------------|
| **Swiss International** (compact grotesque) | Bold presence, almost every mood | Big headlines; can do small paragraphs | Tighten tracking on **headlines** for compactness; leave body tracking alone |
| **Basier / Basier Square** | Cleaner terminals, slightly narrower than Swiss | **Long paragraphs** when you need a sans; diverse layouts | Example settings from course: headline **−4%** tracking, paragraph **−2%** |
| **Ionic** (characterful sans) | Distinctive `K`, rounded figure endings, mixed straight/curve | Headlines with personality | Weak as small body — keep large |

**Sans contexts:** digital UI, tech, beauty, architecture, marketing, public products. Neutral sans usually beats high-contrast serif for long **screen** paragraphs.

### Display / decorative / mono / hand (pairing stars from the course)

| Face | Class | How to use it well |
|------|-------|--------------------|
| **DRAG**, **Champion HTF** (heavy) | Display | Hero words, sports/energy; never long articles |
| **Golden Royale** | Serif | Mix into sans systems for elegance (even single letters/words) |
| **ABC Normal**, **Untitled Sans** | Sans | System/UI/body calm counterpart to louder faces |
| **English 157 BT** | Handwritten | Against heavy display; OK for short body on image-led pages |
| **Byzantium** | Decorative | Big numbers, titles, section marks — highlight of the face |
| **F37 mono** (e.g. Lacan/Tsakma-style) | Mono | Fashion/archive vibe; short all-caps justified blocks or article body at larger sizes |
| **Editor’s Note** | Light serif | Elegant fashion headlines; outstanding small-size readability when light + compact |
| **Fontbas Danner** + **Alipole** | Decorative + serif | Moody portfolio; serif often italic for articles; all-caps serif so it isn’t lost next to decorative |

## How to *use* a font (the part people skip)

### Weight

- **Book / Regular** = default for long reading (named “book” because that’s the job)
- **Bold** = attention. If headline + sub + body are all bold, hierarchy dies
- **Thin / Black** = display moments; both hurt long-text legibility
- Prefer a **family with real italics** if you need quotes / editorial asides

### Size roles (keep to ~1–3 sizes)

| Role | Typical job |
|------|-------------|
| Display | 1–6 words, mood, attraction |
| Title / sub | Section entry, secondary story |
| Body | 40–70ch measure, sustained reading |
| Meta | Nav, captions, numbers, credits |

Do **not** invent five random sizes “for interest.” Change **one** of: size, weight, or space.

### Tracking (letter-spacing)

| Context | Rule |
|---------|------|
| Bold compact headlines (Swiss-like) | Slight negative tracking OK |
| Body / UI | Near default — crushing body tracking kills reading |
| Decorative / display specialty faces | **Do not** retune — spacing is part of the design |
| All-caps labels | Slight positive tracking often helps |

### Leading (line-height)

- Body ~1.4–1.6× (open enough to clear ascenders/descenders)
- Display can go tighter
- If you must go smaller on size, **add** leading to compensate

### Case

- All-caps: nav, labels, short mono blocks — not long paragraphs (unless deliberate short editorial effect)
- Mixed case: default for reading
- Small caps / single serif letter swaps: editorial spice inside a sans headline

### Style tricks that signal “designed”

- Italic for quotes (size bump + reposition so they read as quotes instantly)
- First-line indent or block indent for editorial sections
- Mix two faces **inside one headline** when fusing two brand stories
- Uneven word gaps / credit-style split lines — **short** phrases only
- Overlap type on image only with strong contrast

## Industry → starting fonts (not laws)

| Subject | Default start | Smart break |
|---------|---------------|-------------|
| Fashion / heritage | Serif (Didone display or old-style) | Mono + light serif for 90s magazine |
| Sports | Heavy display + sans | Add traditional serif / hybrid headline for elegant sports (tennis, sailing) |
| Tech / SaaS UI | Neutral sans, book weight | Characterful sans for marketing only |
| Legal / finance | Old-style / transitional serif | Sans for product UI; serif for docs/brand |
| Beauty / cosmetics | Clean sans | Soft serif for campaigns |
| Architecture / interior | Sans, lots of air | Serif captions for editorial case studies |
| Editorial / magazine | Serif body + display or decorative accents | Sans-only modern magazine OK |
| Portfolio / studio | Decorative or mood serif + calm secondary | One face only if the face is strong |
| Code / systems | Mono + one humanist sans | — |

## Named pairing recipes (course)

Copy these structures; swap in licensed / web-available equivalents.

1. **ABC Normal + Golden Royale** — sans system; serif for last headline line / capital accents; all-caps OK; keep both regular so they don’t fight; black/white looks expensive
2. **Champion HTF + English 157 BT** — heavy display + handwritten; split headline across corners; image-led; short copy
3. **Untitled Sans + Byzantium** — earth tones; decorative for numbers/titles/lists; sans for body at larger size
4. **F37 mono + Editor’s Note** — fashion; serif headline, mono body or caps justified; B/W; chapter numbers for balance
5. **Fontbas Danner + Alipole** — moody portfolio; decorative title; serif meta/italic articles; equal-spaced meta row; overlap with contrast
6. **DRAG + GT Sector** (tennis progression) — sports display → introduce traditional serif → hybrid headline words

## Web-available stand-ins (when commercial faces aren’t in the project)

Use these to **match the role**, not to clone the trademark:

| Course role | Web / easier stand-ins |
|-------------|------------------------|
| Caslon all-rounder body | `Libre Caslon Text`, `Source Serif 4`, `EB Garamond` |
| Didone display | `Playfair Display`, `Bodoni Moda` |
| Historic old-style display | `Cormorant Garamond`, `Libre Baskerville` |
| Compact grotesque headline | `Schibsted Grotesk`, `Geist`, `Space Grotesk` (use sparingly — overused), `IBM Plex Sans` condensed-ish weights |
| Clean paragraph sans | `IBM Plex Sans`, `Source Sans 3`, `DM Sans`, `Satoshi` (Fontshare) |
| Characterful sans | `Outfit`, `Sora`, `Syne` (display-leaning) |
| Fashion light serif | `Cormorant`, `Instrument Serif`, `Newsreader` |
| Heavy display | `Bebas Neue` (limited), `Oswald`, `Anton`, better: paid display with real italics |
| Mono editorial | `IBM Plex Mono`, `JetBrains Mono`, `Fragment Mono` |
| Soft handwritten accent | `Caveat`, `Oooh Baby` — keep short |

**Anti-slop:** Do not default to Inter / Roboto / Arial / system for branded marketing. UI products may use a neutral sans — still pick one with character and set it well.

### Next.js wiring pattern

```tsx
import { EB_Garamond, IBM_Plex_Sans } from "next/font/google";

const display = EB_Garamond({ subsets: ["latin"], variable: "--font-display" });
const body = IBM_Plex_Sans({ subsets: ["latin"], variable: "--font-body" });
```

Map CSS:

```css
:root {
  --font-display: /* from next/font */;
  --font-body: /* from next/font */;
}
h1, .display { font-family: var(--font-display); letter-spacing: -0.02em; }
body { font-family: var(--font-body); line-height: 1.5; max-width: 65ch; }
```

Tune tracking in `em` (−0.02em ≈ −2%, −0.04em ≈ −4%).

## Pre-flight before shipping type

- [ ] Body face is book/regular, open counters, average width
- [ ] Display face only on short strings
- [ ] ≤3 primary sizes in the composition
- [ ] Headline tracking tightened only if the face wants it
- [ ] Body tracking not crushed
- [ ] Decorative tracking left alone
- [ ] Measure 40–70ch; leading clears ascenders/descenders
- [ ] Contrast holds on non-Retina
- [ ] Each face has a clear role
- [ ] Pairing matches the brief’s mood (including intentional breaks)
