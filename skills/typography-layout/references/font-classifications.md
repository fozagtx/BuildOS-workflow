# Font classifications

Classifications help you pick a face for a project mood. They are **guidelines**, not laws — intentional breaks (e.g. serif for a sports club with tradition) are encouraged.

For **named favorites, tracking values, industry recipes, and web stand-ins**, read [best-fonts.md](best-fonts.md).

## The seven groups

1. **Serif**
2. **Sans serif**
3. **Script**
4. **Display**
5. **Monospace**
6. **Handwritten**
7. **Decorative**

(Course also treats handwritten and decorative as distinct exploratory groups for pairing.)

---

## Serif

Small strokes at the ends of main strokes. Associated with tradition, formality, editorial reading.

**Common contexts:** Editorial/publishing, traditional brands, legal, finance, historical, fashion with heritage.

### Serif subcategories

| Subcategory | Traits | Classic examples |
|-------------|--------|------------------|
| Old style | Organic, calligraphic, bracketed serifs | Garamond, Caslon |
| Transitional | More refined/balanced, sharper serifs | Times New Roman, Georgia |
| Didone (modern) | High thick/thin contrast, fine serifs | Bodoni, Didot |
| Slab | Bold, squared serifs; strong/modern | Heavy slab families |

**Usage notes from course:**

- High-contrast Didones → great as large display words; weak as long body at small sizes
- All-rounder old-style (e.g. Caslon-like) → headlines **and** long paragraphs
- Prefer readable italics for body when the regular feels weak

**Web stand-ins:** EB Garamond, Libre Baskerville, Playfair Display (Didone-ish display), Source Serif, Fraunces (soft), Rockwell alternatives / Arvo (slab)

---

## Sans serif

No serifs. Clean, simple, minimal. Often easier for UI and long screen paragraphs than high-contrast serifs.

**Common contexts:** Digital interfaces, technology, cosmetics/beauty, architecture/interior, marketing, public-facing products.

**Usage notes:**

- Compact grotesque/geometric sans → bold headlines (often with slight negative tracking)
- Wider/neutral sans → long paragraphs
- Characterful sans (unusual `K`, distinctive figures) → headlines with personality; verify small-size reading

**Web stand-ins:** Inter is default-slop — prefer distinctive options: Geist, Satoshi, Neue Haas-like via commercial, or open faces like IBM Plex Sans, DM Sans, Outfit, Schibsted Grotesk — pick for the project, not habit.

---

## Script

Connected or writing-like strokes. Rounded terminals feel playful; sharp scripts can feel formal/luxury. Usually short phrases, signatures, accents — not long body.

## Display

Built for large sizes and few words. Job is to attract and set mood. Legibility is secondary. Never set articles in a compressed display black.

## Monospace

Fixed advance width. Typewriter / technical / editorial-fashion hybrid moods. Can carry short all-caps justified blocks; for long articles, test carefully and keep size up.

## Handwritten

Looser, human strokes. Strong in editorial when paired against a heavy display (unexpected but powerful). Prefer image-heavy / low-copy contexts if the hand face is the body.

## Decorative

Highly stylized (ornamented caps, novelty figures). Use for numbers, titles, section marks. Pair with a calm sans/serif for paragraphs. Usually **do not** retune tracking — respect the designer’s spacing.

## Quick project picker

| If the project feels… | Start with… |
|-----------------------|-------------|
| Magazine / heritage / literature | Serif (old style or transitional) |
| Product UI / SaaS / docs | Sans, book weight |
| Luxury fashion / perfume | Didone display + calm sans or mono |
| Sports / event / poster energy | Display (+ optional traditional serif for elegance) |
| Portfolio / studio / moody case study | Decorative or character serif + restrained secondary |
| Code / systems / archival | Monospace + one humanist face |

Always validate with real copy at real sizes.
