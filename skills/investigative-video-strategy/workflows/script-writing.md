# Workflow: Script Writing

Use this when the user wants a full or partial documentary script.

## Step 1 — Lock the four answers before writing a single word

Ask the user (or infer from their brief):

1. **Macro question.** What is the ONE question the entire video answers? It must be specific enough to be answered, broad enough to sustain 15–40 minutes. Examples:
   - "How did a single shipping container start a global manhunt?"
   - "Why does the safest nuclear reactor ever built sit empty in a desert?"
2. **Named human.** Who does the viewer follow? Real or composite. They need a name, a job title, and one personal detail by the time they're introduced.
3. **Dramatic irony layer.** What does the viewer know that the people in the story do not? If nothing, the video has no engine. Invent it from the research (you almost always can — the outcome is known, the characters' actions become a countdown).
4. **The 85% reveal.** What lands at the 85% mark that recontextualises everything? This must be planted as an anomaly in the first act.

**Do not start writing until all four are locked.** Push back if any answer is vague.

## Step 2 — Choose a channel signature

Ask the user (or pick based on topic):

- **Geopolitics / crime / intelligence stories** → Cipher signature
- **Conspiracy / unsolved / pattern-of-anomalies stories** → Blackfiles signature
- **Niche historical / corporate / "you've never heard of this" stories** → Fern signature
- **Policy / systemic failure / infrastructure stories** → Hoog signature
- **Manhunt / chase / dual-track investigation stories** → Neo signature

Read the matching `channels/<name>.md` playbook for the full move-set.

## Step 3 — Draft the structure before prose

Produce a beat sheet, not paragraphs. Use this template:

```
[0:00–1:30] HOOK
  - Opener technique: [cold open rewind / paradox hook / framing device / dramatic irony / anomaly plant]
  - Macro question planted: [exact wording]
  - Named human introduced: [name + title + detail]

[1:30–10%] ACT 1 — establish
  - Stakes:
  - Anomaly planted for 85% reveal:
  - First open loop:

[10%–60%] ACT 2 — investigate
  - Mid-loop techniques (2–3): [from TECHNIQUES.md Problem 2]
  - Beats: [chapter / case / roadblock / parallel thread]
    1. ...
    2. ...
    3. ...

[60–75%] PIVOT
  - Third-act recontextualisation: [how the specific story becomes a larger story]

[75%–85%] FALSE SUMMIT (optional)
  - Apparent resolution:
  - Why it was inadequate:

[85%–100%] PAYOFF
  - The reveal that answers the macro question:
  - The systemic / ethical / forward-looking aftertaste:
```

Show this beat sheet to the user. Get approval before writing prose.

## Step 4 — Write prose, one act at a time

Drafting rules:

- **Voice.** Match the channel's voice (see playbook). Default to spare, declarative sentences. No adjectives that aren't load-bearing.
- **Named specificity, every time.** Run a mental scan after each paragraph: did I use "a victim," "an employee," "officials"? Replace with name + role + detail. Always.
- **Open one loop, never close two.** Every section closes the previous loop and opens the next. Never resolve without re-opening.
- **No on-the-nose exposition.** If you find yourself writing "this was important because…" — cut it. Show the consequence; trust the viewer.
- **Read aloud test.** Every paragraph should sound like a voiceover, not an article. If it reads like Wikipedia, rewrite.

## Step 5 — Self-check before delivering

Run this checklist:

- [ ] Macro question stated explicitly within first 90 seconds?
- [ ] Macro question NOT answered before 85% mark?
- [ ] Every named entity has a name, role, and one personal detail?
- [ ] The 85% reveal is the coherent explanation for anomalies planted in Act 1?
- [ ] At least one mid-loop technique from Problem 2 is layered throughout?
- [ ] Does any section feel like a lecture? If yes, rewrite through the human anchor.
- [ ] If the channel signature is Cipher → is dramatic irony active in every scene?
- [ ] If the channel signature is Fern → does the third-act recontextualisation actually land bigger than the specific story?
- [ ] If the channel signature is Hoog → does the closing reveal that the conditions still exist today?
- [ ] If the channel signature is Blackfiles → is there a false summit AND a coherent reveal?
- [ ] If the channel signature is Neo → is the cold open rewind clean (no exposition before the rewind)?

If any check fails, fix before delivering.
